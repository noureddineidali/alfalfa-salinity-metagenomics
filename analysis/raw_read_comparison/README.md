# Raw-read taxonomic comparison

Report 2 compares the CK-1 and MS-1 reconstructions with their corresponding published genus profiles. The three two-sample figures are generated by [`scripts/build_two_sample_raw_read_figures.py`](../../scripts/build_two_sample_raw_read_figures.py), using the canonical genus matrix, validated read counts and Bracken profiles under `results/`.

The CK-1 comparison script retains additional exact-label concordance metrics and tables. Run it from the project root with the Python interpreter from `alfalfa-snakemake`:

```bash
"$(conda info --base)/envs/alfalfa-snakemake/bin/python" \
  analysis/raw_read_comparison/compare_ck1_profiles.py \
  --published data/processed/genus_abundance.tsv \
  --bracken results/taxonomy/raw-read-pilot/CK1_pluspf8_c0_genus.bracken \
  --outdir /tmp/ck1-comparison
```

NumPy and SciPy are required. The script exports `comparison_metrics.json`, `all_genus_exact_label_comparison.csv`, `shared_positive_genera.csv` and `top20_each_profile.csv`. The corresponding validated results are retained here; scientific figures and interpretation are presented in [Report 2](../../report/alfalfa_ck1_raw_read_reconstruction.html).

## Inputs and denominators

Published values come from the validated, source-derived `data/processed/genus_abundance.tsv`. The CK-1 Bracken profile has a single canonical copy at `results/taxonomy/raw-read-pilot/CK1_pluspf8_c0_genus.bracken`. Each profile is divided by its own genus-level total. Genus labels are matched exactly; missing counterpart labels do not establish biological absence. These comparisons measure descriptive agreement between two processing routes, rather than a treatment effect or absolute cell abundance.

The retained `ck1_published_table4_extracted.csv` records the original workbook column, including 12 labels coerced by Excel into date-formatted numbers. It is retained as source-label evidence: its serial-number labels differ from the ISO-date representations in the canonical TSV. None matches a Bracken genus, so the two representations give the same concordance metrics. To reproduce the historical tables with their original serial-number labels, pass this CSV to `--published`; the script accepts both formats. No numerical input values differ.

Database provenance, classification fractions and executed commands are documented in the [raw-read provenance](../../docs/raw_read_provenance.tsv). The original publication does not specify its exact Kraken database build or abundance denominator, limiting exact computational replication.
